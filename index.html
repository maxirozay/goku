Goku CSS

A lightweight, utility-first CSS framework for building modern interfaces

~25KB minified ~5KB gzipped CSS Variables Mobile-first Dark mode

Getting started

Get up and running with Goku CSS in minutes. Choose your preferred installation method:

Package Manager

npm

npm install goku-css

Usage

Import the framework in your project:

// Everything, as source files — your bundler inlines the imports
import 'goku-css'

// Pre-bundled and minified, if you'd rather skip that step
import 'goku-css/bundle'

// Or cherry-pick only what you need
import 'goku-css/css/variables.css'
import 'goku-css/css/elements/button.css'

CDN

For quick prototyping, drop in the pre-bundled build — one request, no import waterfall:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/goku-css">

<!-- or pin a version -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/goku-css@8/docs/index.css">
Pro tip: Start with our CDN for prototyping, then switch to the package manager for production builds.

Customization

Goku CSS is built with CSS custom properties, making it incredibly easy to customize. Change colors, spacing, typography, and more with simple variable overrides.

Quick tip: You can modify any CSS variable directly in your stylesheet or dynamically with JavaScript: 
document.documentElement.style.setProperty('--g-primary', '#your-color')

Dark mode

Colors are declared once with light-dark() and follow the OS preference out of the box. To let users override it, set data-theme on the root element:

document.documentElement.dataset.theme = 'dark' // or 'light'
delete document.documentElement.dataset.theme // back to the OS preference

Overriding a color for a single theme only takes one declaration:

:root {
  --g-bg: light-dark(#fff, #111);
}

Accessibility

The interactive components are built on checkboxes and radios rather than JavaScript, so keyboard and screen reader support comes from the native controls. Two rules make that work:

  • The control that drives a component (the nav toggle, an accordion, a dropdown, a segmented radio) is hidden with position: absolute and a 1px box instead of display: none, so it stays focusable and announced.
  • Focus is never removed, only moved: every control draws --g-outline on :focus-visible, and for hidden inputs the outline is drawn on the label the user actually sees.

Tab through the segmented radios in the Input section to see it — the visible label takes the outline.

.group > input[type="radio"] {
  /* Hidden visually, still focusable and announced. */
  position: absolute;
  width: 1px;
  height: 1px;
  opacity: 0;

  &:focus-visible + label {
    outline: var(--g-outline);
  }
}

Borders

You can add/remove the border-radius on an element with the utility class no-border-radius or border-radius.

The class group will add the radius and remove the radius of the children.

The class b adds a border and a radius on every side — it is the frame used around each demo on this page.

The classes bt, br, bb, bl will add a border to the element, "b" is for border then add the side "t" for top, "r" for right, "b" for bottom, and "l" for left.

bt primary-border br bb bl

Modern CSS Grid utilities for 2D layouts. Perfect complement to flexbox for complex grid systems.

Available classes:

  • grid - Basic grid container
  • grid-fit - Auto-fit columns (uses --g-grid-min-width)
  • grid-fill - Auto-fill columns (uses --g-grid-min-width)
  • col-2, col-3 - Column spanning (2 or 3 columns)
  • w - Span entire width
  • row-2, row-3 - Row spanning (2 or 3 rows)
  • g1, g2, g3 - Gap sizing (works with both flex and grid)

Note: The grid system uses CSS variables for flexibility. Set --g-grid-min-width to customize the minimum column width for auto-fit and auto-fill grids.

Portrait

The portrait class centers an element and caps its width at --g-portrait-width (800px by default), which keeps lines of text short enough to read comfortably. This page's content is a portrait. 

:root {
  --g-portrait-width: 960px;
